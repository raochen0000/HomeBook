# 记账面板验收

以下操作会在所连接的家庭中创建或修改流水，请使用测试家庭。

- 在单人家庭确认不显示记账人；多人家庭用户以户主身份确认日期、时间和记账人并排，普通成员不出现可切换入口。切换记账人后保存，确认流水记录人正确。
- 日期、时间各自点击只打开对应弹层，弹层中不显示「完成」；修改后点击弹层外关闭，再次打开确认值保留且彼此不被覆盖。检查当天显示具体日期，覆盖跨年日期、中文和英文，以及编辑已有流水。
- 保持日期弹层打开，连续选择个位和两位数的日期，确认弹层位置不随日期文字长度改变；时间弹层内切换不同小时、分钟时也应保持位置稳定。
- 使用较长的成员名称，确认日期与时间仍完整展示；记录人名称空间不足时单行尾部省略，VoiceOver 能读出完整名称。
- 日期、时间和记账人入口靠左排列；记账人入口与弹层显示上传头像及缺省头像，弹层不显示标题，成员列表完整，选中状态清楚，点击后关闭并更新记账人。
- 分类图标和名称完整可见，选中项显示蓝环、勾选和蓝色名称；滚动分类后仍可选择。隐藏分类不会因使用频次而重新出现，同名分类仍提示完整路径，编辑旧一级分类时未重选会保留原值。
- 在同一设备分别保存多笔本人支出及收入，确认各自按最近七天的使用次数排序，次数相同保持原顺序；重新打开面板后结果保留。给其他成员记账、编辑或删除流水不计入本机使用次数。
- 新用户或清除应用数据后从原顺序开始；切换用户或家庭时使用频次互相隔离。七天前的使用记录不再参与排序。使用本机保存时间，补记旧日期也应计入。
- 选择继续记账，确认保存后面板、提示、默认分类和新顺序正常；网络失败或超时保留表单，并且未确认成功的操作不增加次数。
- 在小屏和大屏 iPhone 上确认保存按钮与屏幕底部圆角及 Home Indicator 有间距，数字键盘、备注和分类不被遮挡；检查浅色、深色、较大动态字号和 VoiceOver 的日期、成员、分类选中状态。
- 切换中文与英文，确认时间和按钮文案可读；长分类名、成员名在可用空间内可识别。Popover 的显示和关闭不丢失已填写的金额、备注或分类。
