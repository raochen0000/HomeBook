家账支持

家账（HomeBook）帮助家庭记录收支、协作管理账本、预算、储蓄目标和统计报表。

联系我们

使用中遇到问题、需要帮助或希望提出建议，请发送邮件至 homebook-feedback@outlook.com。请在邮件中说明 App 版本、设备型号、系统版本和问题描述；如含截图，请先遮盖账单、联系方式等敏感内容。

账号与数据

你可以在 App 的“我的 → 账号与安全”中管理登录方式、修改资料或发起账号注销。注销后，账号身份与个人资料会按隐私政策处理；为保持家庭账本连续性，历史流水可能保留在原家庭并匿名化。

隐私

请阅读我们的 隐私政策，了解数据收集、使用、保存和删除方式。
